# Color Converter

A compact browser tool to convert colors between HEX, HEXA, RGB, RGBA, HSL, HSLA, and CMYK.

## Features

- Visual saturation / brightness picker
- Hue and opacity sliders
- Live preview with transparency
- One-click copy for every format
- Paste or type any supported color value
- Common color swatches

## Live demo

After GitHub Pages is enabled:

`https://abhisekumar.github.io/color-converter/`

## Run locally

Open `index.html` in a browser, or:

```bash
npx serve .
```

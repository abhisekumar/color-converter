# Color Converter

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://abhisekumar.github.io/color-converter/)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Free online **color converter** for designers and developers. Convert between **HEX, HEXA, RGB, RGBA, HSL, HSLA, and CMYK** with a live picker and opacity control.

**Live demo:** https://abhisekumar.github.io/color-converter/

## Why use it

- Convert hex to rgb, hsl, and cmyk in one place
- Preview transparent colors on a checkered background
- Copy any format with one click
- Paste a color value and get every format instantly

## Features

- Visual saturation / brightness picker
- Hue and opacity sliders
- Live preview with alpha support
- One-click copy for every format
- Paste or type supported color values
- Common color swatches

## Tech

- Pure HTML, CSS, and JavaScript
- Client-side only (GitHub Pages)
- No libraries required

## Run locally

```bash
npx serve .
```
